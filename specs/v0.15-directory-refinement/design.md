# v0.15 目录逻辑与日历内容完善设计

## 1. 目标结构

```text
首页
├─ 关于
├─ 部门
├─ 活动
│  ├─ 精选活动
│  ├─ 时间轴
│  ├─ 历史上的今天
│  └─ 照片墙
├─ 档案馆
│  ├─ 资料库
│  ├─ 文章库
│  ├─ 主题标签
│  └─ 口述史
└─ 加入我们
```

档案馆首页只做“四类档案入口”的总目录；活动仍是一级栏目，档案馆只保留一条轻量的“关联活动台账”链接。

## 2. 实施分层

### 2.1 配置层

文件：`docs/.vitepress/config.mts`

- 保持现有七项顶栏顺序。
- 活动侧栏移除手工年份项，保留“活动总览”和“年度总结”入口。
- 如 VitePress 配置无法在构建期动态生成侧栏年份，则由 `ActivityTimeline.vue` 在活动页内部生成年份索引，配置不再声称侧栏自动化。
- 继续保持各栏目侧栏隔离，单篇活动/资料/文章不进侧栏。

### 2.2 档案馆内容层

文件：`docs/archive/index.md`、`docs/activity/index.md`

- 档案馆移除活动的完整精选列表，只保留“活动台账”说明和一个入口。
- 活动页继续承载精选活动和时间轴，不复制资料/文章/标签/口述史入口。
- 档案馆四个入口使用同一种卡片/链接层级，避免一个用标题、一个用列表、一个用随机按钮造成层次不齐。

### 2.3 日历数据层

文件：`data/article-catalog.template.csv`、`docs/.vitepress/data/articleCatalog.data.js`、`docs/.vitepress/data/solarTerms.js`、`docs/.vitepress/data/festivals.js`

CSV 从 7 列扩展为 8 列：

`标题 | 发布日期 | 原文链接 | 平台 | 分类 | 作者 | 状态 | calendar_key`

规则：

1. `calendar_key` 为空表示普通文章，不参与首页日历关联。
2. 只有完整日期、公开 `http(s)` 链接和匹配键同时满足时才可链接。
3. 同一键存在多篇文章时，选择发布日期最近的一篇。
4. 节日/节气数据表中的每个事件增加稳定 `key`，显示名和文章匹配逻辑分离。
5. `SeasonTerm.vue` 只调用“按当天事件找键值文章”的函数，不直接对文章标题做模糊猜测。

### 2.4 标签层

短期先把 `docs/tags/index.md` 文案改为“活动与资料标签”，与当前数据源一致。文章标签不在本轮强行混入；若后续扩展，另增加 CSV `tags` 字段和独立迁移任务。

### 2.5 随机回忆层

文件：`docs/.vitepress/data/randomPages.js`

只保留公开内容：活动详情、荣誉、矩阵、部门、资料条目、文章专题。移除维护教程、交接手册、收录规范和演示页。随机池为空时保留现有按钮但显示稳定的空状态，不抛出运行时错误。

### 2.6 文档层

同步文件：`PLAN.md`、`docs/library/spec.md`、`docs/demo/sidebar.md`、`docs/demo/search.md`、`docs/maintainer/update-tutorial.md`。

- 统一“四类档案入口”“局部侧栏”“calendar_key”“文章目录已上线/原始层待授权”等措辞。
- 修正香港天文台参考链接，优先指向可访问的年度对照表或官方入口。
- 保留历史版本说明，但明确标注“历史方案”，不让维护者照抄旧配置。

## 3. 数据迁移方案

1. 在 CSV 表头末尾新增 `calendar_key`。
2. 为现有 3 行数据补空字段，不改变原有标题、日期、链接和状态。
3. 更新 `articleCatalog.data.js`：接受 7 列旧行和 8 列新行，输出 `calendarKey: ''` 或实际键。
4. 更新 `scripts/audit-links.cjs`：校验 8 列新格式，同时兼容 7 列旧数据的过渡期。
5. 在收录规范中增加键值表和示例，先只为有明确对应关系的文章填写键。

## 4. 验证设计

### 静态验证

- 构建产物递归扫描 47 页以上的页面集合，确认档案馆不再出现活动精选重复块。
- 检查活动页存在时间轴和年份索引；档案馆存在四类入口。
- 检查节日/节气无键文章不会生成链接，有键文章只链接匹配项。
- 检查随机池中不存在维护和 demo 路径。

### 浏览器验证

- 桌面：从首页进入活动和档案馆，确认两条路径职责不同。
- 移动端：打开菜单、进入活动/档案馆/加入我们，确认无换行和横向溢出。
- 日历：在测试时钟或临时数据分支验证固定节日、农历节日、非事件日和文章缺省状态。
- 线上：推送后硬刷新并带查询参数访问，确认不是旧缓存。

## 5. 回退方案

实施前创建 `backup-v0.14-directory` tag。若任一阶段失败，只回退本轮提交，不删除之后新增的历史内容；CSV 迁移失败时先恢复 7 列读取兼容，再重新处理数据迁移。
