# v0.15 目录逻辑与日历内容完善需求

## 1. 目标

在不删除既有页面和 URL 的前提下，解决当前站点的四类核心问题：

1. 活动栏目与档案馆首页职责重叠。
2. 节日/节气文章按日期猜测，存在误链风险。
3. 活动时间轴自动化，但侧栏年份仍需手工维护。
4. 标签、随机回忆和维护文档的内容边界不够明确。

## 2. 不变项

- 顶栏继续使用：`首页 / 关于 / 部门 / 活动 / 档案馆 / 加入我们 / 成员端`。
- 首页、`/activity/`、`/archive/`、`/friends/`、`/maintainer/` 等既有 URL 全部保留。
- 不删除历史活动、年册、资料条目或文章目录记录。
- 不改变 GitHub Pages、域名、Cloudflare、Docker 或部署方式。
- 不升级 VitePress、Vite 或现有插件；CSV schema 扩展必须保持向后兼容。
- 友情链接仍然只是“关于”下的收纳入口，不把静态站隐藏当作权限控制。

## 3. 用户故事

### 访客

- 我想看“做过什么”，进入活动后不会再次看到一套重复的档案馆目录。
- 我想看“留下了什么”，进入档案馆后能直接选择资料、文章、标签或口述史。
- 我在节日/节气当天看到的文章链接必须确实对应这个事件，不能因为同一天有别的文章而误链。
- 我点“随手翻开一页”时只看到公开内容，不会误入维护手册或组件演示。

### 维护者

- 新增活动后，时间轴、年份导航和相关索引不需要分别手工登记。
- 给文章填写一个明确的日历事件键后，首页能稳定关联该事件；没有键就不自动猜测。
- 维护文档、演示页和实际配置对同一规则使用同一说法。

## 4. 验收标准（EARS）

### R1 活动与档案馆边界

- 当访客打开 `/archive/` 时，系统应展示资料、文章、主题标签、口述史四个核心入口，并只保留一个指向活动台账的关联入口。
- 当访客打开 `/activity/` 时，系统应看到精选活动、时间轴、历史上的今天和照片墙，不再重复展示档案馆四库入口。
- 当访客从档案馆进入任一核心入口时，系统应在两次点击内到达目标页面。

### R2 年份导航一致

- 当 `docs/activity/` 新增某个年份的活动页面时，系统应在构建产物的活动年份导航中出现该年份，或由活动页自动生成可点击的年份索引。
- 当活动年份没有条目时，系统不得显示空年份分组。
- 当维护者新增活动时，不得同时要求修改活动数据文件、时间轴列表和单篇侧栏。

### R3 日历文章不误链

- 当节日或节气当天存在带明确 `calendar_key` 的公开文章时，系统应只链接键值匹配的最近年份文章。
- 当当天没有键值匹配文章时，系统应显示事件名称但不生成文章链接。
- 当目录中只有同日期但无 `calendar_key` 的其他文章时，系统不得把该文章作为兜底链接。
- 当旧 CSV 行没有 `calendar_key` 列或该字段为空时，系统应继续正常构建并视为未关联文章。

### R4 标签边界

- 当访客进入主题标签页时，页面应明确说明当前标签覆盖范围。
- 在文章标签数据未接入前，系统不得暗示文章库已经参与标签聚合。

### R5 随机回忆范围

- 当访客点击随机回忆时，目标页面应属于公开活动、荣誉、部门、资料或文章内容。
- 随机池不得包含 `maintainer/`、`demo/` 或内部操作说明页面。

### R6 文档一致性

- 当维护者阅读 `PLAN.md`、`docs/library/spec.md`、`docs/demo/sidebar.md` 或更新教程时，目录规则、CSV 字段和自动化状态应与代码一致。
- 当实施完成时，文档不得继续出现“三库共用侧栏”“活动年份完全自动”等与实际不符的描述。

### R7 回退与验证

- 当本轮实施开始前，Git 中应存在可恢复 v0.14 的 tag 或 commit。
- 当构建、链接审计或浏览器验收失败时，系统不得推送未验证版本。

## 5. 明确决策

- 日历文章关联采用 CSV 可选字段 `calendar_key`，不再使用“同月日任意文章”兜底。
- `calendar_key` 使用 ASCII 稳定键，例如 `solar-white-dew`、`festival-teacher-day`，展示名称仍来自节气/节日数据表。
- CSV 扩展保持兼容：旧 7 列行自动补空键；新 8 列行才可建立关联。
- 农历日期继续由 `Intl` 中国农历日历计算，年度以香港天文台对照表抽查。

## 6. 非目标

- 本轮不导入公众号原始 HTML，不抓取微信接口，不实现后台管理。
- 本轮不把文章正文、评论、阅读量或私密素材放入公开站。
- 本轮不新增留言墙、社交平台自动同步或登录系统。
