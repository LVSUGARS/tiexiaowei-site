# "铁小微"带你看江苏铁路教育馆

学校继续教育学院推出"铁小微带你看江苏铁路教育馆"社区教育活动,面向南京市中小学生开放,铁小微融媒体编创中心承担记录与传播工作。

- 接待南京市鼓楼、玄武、浦口等区 **9 批近 500 名中小学生**
- 围绕铁路历史与轨交科普开展场馆研学

> 来源:[借势特色教育场馆打造社区教育新亮点(新华报业网)](https://www.xhby.net/content/s691ec678e4b054c4a0b07fbb.html)
