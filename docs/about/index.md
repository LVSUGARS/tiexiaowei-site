# 中心简介

铁小微融媒体中心是南京铁道职业技术学院党委宣传部领导下运营全校新媒体矩阵的学生团队。"铁小微"是学校融媒体的统一品牌形象——"铁"取自铁道特色,"小微"是新媒体 IP 形象。

## 我们做什么

- **运营四端新媒体矩阵**:微信公众号、微博、抖音、中国大学生在线校园号
- **记录校园**:招生宣传、校园文化、师生风采、重大活动(毕业典礼等)
- **创作融媒产品**:短视频、图文专题(如《二十四节气专题》)、海报与视觉设计
- **协同宣传**:配合学校思政品牌"铁小燕"流动微宣讲等专项工作

## 本站是什么

本站是铁小微融媒体中心的**官方介绍页与内容档案馆**:

- 介绍中心、展示代表作品与荣誉
- 归档公众号历史文章与历年活动记录(建设中)
- 提供成员端与新生报名的统一入口(见首页"系统入口")
