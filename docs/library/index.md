# 文章库

文章库是本站的核心特色功能:把**公众号、校园号等各平台**发布的内容全量归档到站内,让每一届的作品都可检索、可传承。中国大学生在线校园号专栏也已并入本板块(见侧栏)。

## 归档架构(三层模型)

1. **原始层(保真)**:公众号原始 HTML + 本地化图片,静态保存、永不加工
2. **索引层(检索)**:目录表驱动,按年份/分类浏览 + 站内搜索
3. **精读层(门面)**:代表作手工重排为站点页面(如《二十四节气专题》)

## 为什么值得做

公众号推文在微信生态之外几乎无法检索,一届届学生记者的作品和经验随换届散失。文章库就是给铁小微补一个"微信之外的档案层"——先建目录(标题、日期、链接),正文逐步补齐,哪怕中途停下,目录本身已经是完整的馆藏书目。
