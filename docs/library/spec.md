# 收录规范

文章库的数据唯一源是**文章目录表**,所有浏览页、检索页均由目录表自动生成——维护者只填表,不写页面。

## 目录表字段(八列)

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 标题 | 推文原标题 | 职教周:铁路科普系列短视频上线 |
| 发布日期 | 格式 `YYYY-MM-DD` | 2022-05-13 |
| 原文链接 | 微信推文永久链接 | https://mp.weixin.qq.com/s/... |
| 平台 | 微信公众号 / 校园号 / 其他 | 微信公众号 |
| 分类 | 招新 / 活动 / 科普 / 校园文化 / 通知… | 科普 |
| 作者 | 团队或个人(经同意) | 铁小微编创中心 |
| 状态 | 已收录原文 / 仅目录 / 缺失 | 仅目录 |
| calendar_key | 可选的日历事件键;仅用于首页节日/节气关联 | solar-white-dew |

模板文件:`data/article-catalog.template.csv`(仓库根目录 `data/` 下),用 VS Code 或表格软件编辑,保存为 UTF-8 编码。

## 节气/节日文章关联(首页彩蛋)

首页节气和固定公历节日徽章通过 `calendar_key` 从文章目录中找到对应原文,不另建一套文章数据:

1. `calendar_key` 为空表示普通文章,不参与日历关联。
2. 键必须与节日/节气数据表中的键完全一致;例如白露用 `solar-white-dew`,教师节用 `festival-teacher-day`。
3. 同一键有多篇文章时,只选择发布日期最近的一篇;只有日期完整且原文链接为 `http(s)` 时才会生成链接。
4. 没有键值匹配文章时仍显示“今日节气/节日”,但不显示空链接或按标题、日期猜测的链接。

旧版七列表头和缺少第八列的旧数据行仍可读取,会自动将 `calendar_key` 视为空。春节、端午、中秋等农历节日由内置中国农历日历按北京时间计算,不在表中写死公历日期;每年可参考[香港天文台天文年历](https://www.hko.gov.hk/en/gts/astron2026/almanac2026_index.htm)(公农历对照,官网按年更新)抽查。

## 原始文章存放约定(二期)

```
data/wechat-archive/
├── 2022/
│   ├── 05/
│   │   ├── article-<日期>-<序号>.html
│   │   └── images/
│   └── ...
└── manifest.json   # 导出元数据(工具自动生成)
```

- 原始 HTML **永不手工修改**,保持与微信端一致
- 图片必须本地化保存——微信图片域名 `mmbiz.qpic.cn` 有防盗链,热链必然裂图
- 每次导出保留原始导出包(网盘 + GitHub Releases 各一份),用于对账与重建

## 对账规则

1. 录入前先确认公众号历史文章总数(后台或资料页)
2. 目录表填完后核对:总篇数一致、日期无异常断档
3. 随机抽查 10 篇:链接可打开、图片显示正常

## 增量节奏

每学期末由当值成员补录本学期新增文章;推荐部署 `wewe-rss` 实现新文章自动提醒。历史数据的批量导出方案见计划书(PLAN.md)第五节。
