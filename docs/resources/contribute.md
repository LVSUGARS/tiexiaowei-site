# 收录指南:如何贡献一个资料条目

贡献一个条目 = **新建一个 md 文件,照模板填空**。不需要碰任何页面代码。

## 三步走

1. 在 `docs/resources/entries/` 下新建 md 文件(文件名用英文或拼音,如 `camera-basics.md`)
2. 粘贴下面的模板,填 frontmatter 和正文
3. 提交 PR(或直接发给维护者代发)

## 条目模板

```md
---
title: 资料标题
date: 2026-09-06
type: 学习资料          # 学习资料 / 培训资料 / 素材包
source: 2026-09 摄影基础培训   # 来源:某次培训 / 某场活动 / 某部门
permission: 公开         # 公开 / 仅成员
tags: [摄影, 入门]
---

# 资料标题

一段说明:这是什么、谁整理的、适合谁看。

![示意图](./images/xxx.jpg)

**网盘链接**:https://(带提取码写在这里)

> 仅成员级条目:此处不写真实链接,写"存放位置:成员端 > 素材库 > XX 文件夹"。
```

## 注意事项

- **图片**:压缩后与 md 文件同目录存放(或站内图床路径),单张建议 ≤ 300KB
- **网盘链接**:优先使用中心统一网盘;设置提取码的写清提取码;**不要用个人私人网盘做唯一存储**(人毕业链接就死)
- **仅成员级**:真实链接绝不写进公开站;页面只记录存放位置
- **来源关联**:如果资料来自某场[活动](/activity/)或[培训](/activity/),记得在 `source` 里写清,活动页也会链接过来
