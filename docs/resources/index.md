## 权限分级(重要)

| 级别 | 内容 | 处理方式 |
| --- | --- | --- |
| **公开** | 学习资料、培训成果、可对外展示的花絮 | 直接上站,链接可访问 |
| **仅成员** | 原始素材包、含学生肖像的未发布照片 | 页面只记录"存在与存放位置";真实链接走[成员端](https://njrts.txwrmtzx.top/member/)或受权限保护的网盘,**不在公开站暴露** |

涉及人物肖像的素材,上站前须征得本人同意。
