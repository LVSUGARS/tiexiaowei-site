# 口述史

> 档案馆最柔软的部分:推文记录"我们做了什么",口述史记录"那些没写进推文的晚上"。每年采写两三篇,就是给未来的珍贵史料。

## 采访提纲(模板)

1. 你是哪一年、怎么加入铁小微的?
2. 印象最深的一次拍摄 / 一篇推文?
3. 有什么当时觉得是灾难、现在觉得好玩的事?
4. 在中心学到的、后来一直用得上的东西?
5. 想对现在的新成员说什么?
