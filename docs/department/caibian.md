# 采编部(A/B 两组)

> 职责为拟定稿,以中心内部确认后的版本为准。成员与负责人 🚧 待补。

## 定位

中心的**文字与内容策划中枢**:微信公众号等平台的内容,从这里选题、成稿、审校。分 A / B 两个并行编组。

## 日常任务(拟定)

- 活动采写与推文撰稿(配图与影像部协作)
- 公众号栏目策划与选题会组织
- 深度内容:人物专访、专题策划(如《二十四节气》类的系列选题)
- 推文排版与发布前审校

## 用到的技能

- 新闻敏感与标题功夫
- 采访提纲与成稿结构
- 排版工具(秀米 / 135 等)与审校细心
