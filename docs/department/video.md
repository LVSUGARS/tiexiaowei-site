# 视频部(A/B 两组)

> 职责为拟定稿,以中心内部确认后的版本为准。成员与负责人 🚧 待补。

## 定位

中心的核心内容生产部门:负责全校各类活动的**摄像与成片**——开学典礼、运动会、迎新晚会、毕业典礼,以及中心自制的短视频与专题片。分 A / B 两个并行编组,大型活动协同上阵。

## 日常任务(拟定)

- 活动多机位摄像(预告片、现场记录、精华切条)
- 短视频 / 专题片策划、拍摄与成片
- 素材整理归档,上传[资料库](/resources/)并登记
- 与采编部配合完成推文视频、与设计部配合封面包装

## 用到的技能

- 摄像基础:运镜、收音、分镜意识
- 剪辑:剪映 / Pr,字幕、调色、卡点
- 素材命名与归档习惯
