# 部门总览

铁小微融媒体中心下设多个部门,各部门分工不同,且**构成每年随换届调整**。本板块用两层结构记录:

1. **职能页**:每个部门一页,写清定位、日常任务、用到的技能——相对稳定,偶尔修订
2. **按年年册**:当年有哪些部门、负责人是谁——换届归档,撤并新设全部留痕

## 如何维护

- 部门职责有调整:直接改对应职能页
- 换届:复制 `2026.md` 为新年册,填入新一届名单;历史年册永不删除
- 新设部门:在 `docs/department/` 新建 md 并在 `config.mts` 侧栏登记
