## 关联活动台账

每场发生过的工作，包括未公开的拍摄任务，都记录在[活动存档](/activity/)中；它是持续发生的工作台账，不属于档案馆的四类长期馆藏。

资料库、文章库与标签索引已接入构建期自动化；公众号原始 HTML 和真实口述史内容仍需后续内容生产与授权。
